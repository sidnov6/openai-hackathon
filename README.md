# Homi

**Feel like home.** Homi is a map-first Frankfurt student-housing assistant for sourced residence discovery, explicit fictional demo tenancy acceptance, clause-cited lease explanations, conditional German-law review, and move-in/move-out evidence planning.

## Run locally

Requirements: Node.js 24+ and pnpm 11.

```bash
cp .env.example .env
pnpm install
pnpm dev
```

The web app runs through Vite and proxies `/api` to the Fastify service at `http://127.0.0.1:8787`. Without keys, the app must label saved discovery and limitations; it never presents mock or stale records as live availability.

Useful checks:

```bash
pnpm build
pnpm test
pnpm test:e2e
pnpm typecheck
```

## Import the supplied fictional policies

Policy contents are deliberately not generated by this repository. The importer accepts `.docx`, PDF, Markdown, and text. Files may use `policy-001`…`policy-020` or corpus names beginning `DE-RA-001`…`DE-RA-020`, then run:

```bash
pnpm import:policies -- /absolute/path/to/policies --require-all
```

The importer validates IDs, file signatures, duplicates, extraction coverage, immutable SHA-256 versions, and the persisted listing-policy mapping. Raw documents and evidence stay under the private `UPLOAD_DIR` and are ignored by Git.

## Data boundaries

- Residence/location facts come from the official Studierendenwerk Frankfurt directory and retain source URLs and timestamps.
- Availability defaults to `unknown`; a residence directory entry is not a vacant-room claim.
- Each of 20 stable slots pairs a real residence with a separately supplied fictional policy. The pairing is always labeled `fictional_demo`.
- Demo acceptance is local simulation only. Homi never sends a provider message, takes payment, signs a lease, or claims a real acceptance.
- Legal results are sourced information and triage, not a legality score or definitive individualized legal advice.

## Hosted demo

The private ChatGPT Site is available at https://mainhaus-frankfurt.frankfurt-sc-7017.chatgpt.site. It uses the visibly labeled sample-data adapter because it is a static deployment. Run `pnpm dev` for the complete live-source, persisted-corpus, evidence-upload, and on-demand model workflow.
